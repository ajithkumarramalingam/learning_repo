1. There are 3 types of parameters in Stored Procedures

| Type    | Meaning            | JavaScript Example                  |
| ------- | ------------------ | ----------------------------------- |
| `IN`    | Receive a value    | `function add(a)`                   |
| `OUT`   | Return a value     | `return total`                      |
| `INOUT` | Receive and return | Modify and return the same variable |
